finesse teaches your coding agent the invisible details that make interfaces feel polished, fast, and physical. To show what that is worth, we gave Opus 4.8 the same prompt fifteen times. The only thing that changed was whether it read finesse first.

$ npx skills add arjunlohan/finesse

Each pair below is the same component, built twice. Same model, same prompt, same effort. Hover, click, and spam both. Most of the difference is felt, not seen. And the honest part. Opus 4.8 on its own is already good. finesse is the refinement that compounds: the easing that leaves a touch faster than it arrives, the loader that knows not to flash, the state the baseline forgot.

Felt, not seen.

Great interfaces are an accumulation of small, individually invisible details that compound. finesse packages them as committed defaults. Motion, interaction states, surfaces, typography, performance, and accessibility, so your agent reaches for them without being asked.
